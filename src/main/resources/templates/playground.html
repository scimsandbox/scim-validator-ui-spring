SCIM Users API

Manage identities via RFC 7643 & RFC 7644. Click any operation below to expand and test.

GET

1. List Users with Pagination & Filters

Retrieves a paginated list of users wrapped in a ListResponse envelope.

RFC 7644 §3.4.2
Pagination uses startIndex (1-based index) and count (number of items). Combine with filter to query specific users.
Examples:
GET /Users?startIndex=1&count=10
GET

2. Get User by ID

Retrieves a single user resource by identifier.

RFC 7644 §3.4.1
GET /Users/{id}
POST

3. Create User

Provisions a new user identity in the SCIM directory.

RFC 7644 §3.3
POST /Users
PATCH

4. Update User Attribute

Mutates specific user attributes using PatchOp operations.

RFC 7644 §3.5.2
PATCH /Users/{id}
PUT

5. Replace User

Replaces all attributes of the user resource completely.

RFC 7644 §3.5.1
PUT /Users/{id}
DELETE

6. Delete User

Permanently removes the user resource from the SCIM directory.

RFC 7644 §3.6
DELETE /Users/{id}
